# Source Briefings

This folder contains historical source material used to develop the LEXOS system specification.

The file:

`LEGACY OLD - Briefing_ LiNKtrend Legal Operating System (LEXOS).md`

is legacy background material only.

It is **not** the controlling system specification.

The controlling LEXOS system definition is located in:

`docs/lexos-system-spec/`

The implementation-control documents are located in:

`docs/implementation/`

If there is any conflict between the legacy briefing and the numbered LEXOS system-spec documents, the numbered system-spec documents control.

If there is any conflict between the legacy briefing and implementation-control documents, the implementation-control documents control for MVP build execution, subject to the numbered system-spec documents as architecture authority.
